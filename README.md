# AirliftExtended
Real Rapid Deployment is now possible.
Units can now be airlifted directly to an Airstrip or its adjacent plots.

REQUIREMENTS:
- Aerodrome with an Airport
- Rapid Deployment Civic

COST:
- 10 Oil per airlifted Military/Support/Religious/Hero/Military Great People unit
- Free for Settlers/Builders/Civilian Great People

PENALTY:
- Each missing Oil inflicts +5 Damage upon landing (Max 50)
- If no health is left, the unit can be killed in a crash landing
